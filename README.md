## 📖 About

Project 001 is the complete redesign and redevelopment of my personal portfolio.

Rather than creating another static portfolio website, this project is being built as a **production-ready full-stack application** with a secure admin dashboard, dynamic content management, modern UI/UX, and scalable architecture.

The goal is to create a portfolio that evolves throughout my engineering journey while showcasing real-world software engineering practices.

# 📌 Repository Timeline

This repository originally hosted the first version of my personal portfolio.

Instead of continuing to improve that implementation, I decided to start over with a completely new architecture, modern technologies, and a better engineering approach.

The previous version remains part of this repository's Git history, while the current branch represents the beginning of **Project 001**—a complete rebuild from the ground up.
